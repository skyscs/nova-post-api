Нам нужно реализовать собственный API сверху базы данных почтовых отделений NovaPost
Базу данных можно получить по ссылке @https://api-cdn.novapost.pl//dictionary//divisions/mobile/full//en/versions.json 
1) Нам нужно создать механизм, когда мы будем раз в день проверять ссылку, и в случае появления новой базы, обновлять нашу.
2) Сама база в json формате, и занимает около 500Мб.
3) Нам нужно придумать, как мы будем эту базу хранить для быстрого доступа к данным, нам нужно иметь возможность поиска ближайших отделений пользователя, с тем, чтобы в будущем отобразить их на карте. Нужно иметь возможность получения списка всех стран, и городов, где есть хоть одно отделение, и список всех отделений города.

Мы можем выбрать любой эффективный инструмент, например PostGIS, поднять стек в докере, и иметь возможность деплоя всего на наш сервер, чтобы он там по крону уже проверял и актуализировал базу.
В качестве базы предлагаю использовать bun + hono, typescript, но если нам нужно что-то более тривиальное, то подумай, и скажи.
Наш код мы будем деплоить на VPS сервер, на котором уже есть другое API, и нам нужно будет аккуратно сделать так, чтобы оба API работали рядом, не мешая друг другу, а дополняя.
Деплой нужно сделать через Github Actions.
